## Phase 2: Performance Optimization - PLANNING COMPLETE

### Root Cause:
- Every simulation cycle triggers full view updates
- Causes excessive DOM/Three.js updates
- UI is not smooth

### Solution Plan Created:
1. Add `updateVisuals` flag to C++ cycle JSON (true every 10 cycles)
2. Heatmap updates only when `updateVisuals` is true
3. Failure map updates on init + when new failures occur
4. 3D Grid:
   - Update paths when new requests routed
   - Update TSV colors when failures occur
   - Update traffic colors every 10 cycles (in traffic mode)
   - Update immediately on color mode change

### Files to Modify:
- C++: src/simulator.cpp
- Web: types/simulation.ts, stores/simulation.ts, 3 view components
